# Control por Voz para Carro Arduino 🚗🤖

Aplicación móvil híbrida optimizada para mi **Samsung Galaxy A50**, desarrollada con tecnologías web nativas y compilada mediante **Capacitor** y **Android Studio**.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Manipulación del DOM).
- **Mobile:** Capacitor Core & CLI / Android Studio WebView.
- **Hardware:** Arduino (Control de motores vía comandos string por Bluetooth Serial).

## 🚀 Características
- Captura de voz en tiempo real desde el dispositivo móvil.
- Envío automatizado de caracteres de control (`F`, `B`, `L`, `R`) al monitor serial.
